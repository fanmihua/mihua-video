# mihua-video：用 AI 做讲解视频的工作流

把一份口播稿交给 AI 编程助手（Claude Code、Codex 都行），做成带镜头运动、字幕、配音、配乐的讲解视频：深灰舞台、左上角手写签名、右上角头像、章节导航，真实截图和录屏上推拉、框选、标注，代码画的插画。画面全部是 AI 写的网页代码，用 [HyperFrames](https://hyperframes.heygen.com) 在你自己的电脑上渲染成视频。

仓库里有两样东西：一个 skill（流程、规则、工具、品牌层），和一支用它做出来的 14 分 48 秒讲解视频《用 AI 做一支讲解视频》的完整工程（口播稿、每一章的画面代码、插画；她的头像签名和旧视频片段换成了灰色占位），给 AI 当参考。

作者：范米花儿

## 开始之前

- **只支持 Apple 芯片的 Mac**（M1 及以后）。
- 视频在你自己的电脑上渲染：内存 32 GB 及以上出 4K，16–31 GB 出 2K，16 GB 以下出 1080p，脚本会按你的电脑自动定。
- 第一次装要下载约 6 GB（运行环境和转写模型），硬盘留 20 GB 以上。
- 字体用阿里巴巴普惠体、阿里妈妈数黑体，免费商用，要你从 [阿里巴巴字体](https://www.alibabafonts.com) 下载安装（仓库里不带，安装脚本会提醒你）。
- 配音两条路：自己录口播；或在 [Fish Audio](https://fish.audio) 克隆你自己的声音，要你自己注册、付费（见 `配音设置.md`）。

更多要知道的（电脑配置对照表、每一关看什么、常用的几句话）在 **`先看这个.md`**。

## 三步上手

1. 下载这个仓库（Code → Download ZIP，或 `git clone`），放到一个固定的位置。
2. 在 Codex 或 Claude Code 里打开这个文件夹，说：
   > 帮我装好。

   文件夹里给 AI 写了说明（`AGENTS.md`），它会自己装好软件和 skill，再列出要你自己做的几件事：装字体、给一张头像和一张手写签名的照片、选配音。
3. 装好以后新开一个聊天，说：
   > 用 mihua-video 做一支讲解视频，讲……，给……看。

   AI 照流程走：口播稿 → 配音 → 分镜 → 静帧 → 样片 → 成片，每一关停下来给你看。第一支建议先做一两分钟的短片。

## 里面有什么

| | 是什么 |
|---|---|
| `mihua-video/` | skill：`SKILL.md` 是流程；`references/` 是规则（写稿、画面、素材、声音、封面、踩过的坑）；`assets/kit/` 是品牌层和工具（配音、对时间、配乐、混音、出片、封面）；`scripts/` 是一键安装、建工程、把你的照片做成头像和签名 |
| `示例_幕后协作/` | 一支 14 分 48 秒讲解视频的完整工程：口播稿、每一章的画面代码、代码画的插画、配置、时间轴、封面、字幕（看它的 `README.md`） |
| `先看这个.md` | 给你看的：开始之前一定要知道的、必须你来做的、每一关看什么 |
| `配音设置.md` | 配音的几条路、价格、怎么选 |
| `AGENTS.md`、`CLAUDE.md` | 写给 AI 的接手说明（同一份），你不用看 |
