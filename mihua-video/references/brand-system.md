# 品牌层规格（固定）

这些元素出现在每一支视频里，观众靠它们认出「这是同一个人的视频」。实现都在 `assets/kit/`，工程里不要改；要改就改 skill，让以后所有视频一起变。签名、头像、声音换成用户自己的，见最后「换人使用」。

| 元素 | 规格 | 为什么 |
|---|---|---|
| 画面 | 1920×1080 舞台，渲染 2 倍到 3840×2160（4K），30fps | 文字和截图在手机上放大也清楚 |
| 舞台 | 深灰径向渐变（中心 #2e2e2f → 边缘 #111112）+ 顶部一排虚焦方块缓慢横移 + 底部一条虚焦条 + 暗角 + 颗粒（每 2 帧跳动） | 有景深、有胶片感，不是死黑底 |
| 签名 | 左上角用户自己的手写问候（比如「嗨，我是 ×××」，`assets/img/signature.png`），高 66px，开口说第一句时从左到右写出，之后整片保留 | 认得出是谁 |
| 头像 | 右上角，64px 圆形，白色描边，和签名在同一条中线上，签名写出后 0.4 秒浮现 | 认得出是谁 |
| 章节导航 | 顶部居中一行小字「01 xxx 02 xxx …」，当前章白色 + 下划线，其余 58% 白（低于这个手机上看不清，检查也过不了）；内容来自 `video.config.json` 的 chapters | 讲解类视频的结构感，不像广告 |
| 字幕 | 阿里妈妈数黑体 38px（4K 下 76px），白字 + 黑色柔影，底部居中 54px；`【关键词】` 反白（白底黑字方块从左擦出） | 统一、好读；关键词有记忆点 |
| 标注 note | 圆点 + 56px 引线 + 深色半透明小标签（普惠体 22px，副文 18px 灰） | 说明画面是什么，不抢画面 |
| 框选 outline | 一黑一白两圈：`.outline` 白圈在里、黑圈在外（放在深色舞台、深色标题栏上）；`.outline.dark` 黑圈在里、白圈在外（放在白色截图、浅色界面里面）。放在什么底上都至少有一圈看得见 | 指出口播说到的位置 |
| 窗口 win | 圆角 14px，深色标题栏（三个灰点 + 一行灰字），软投影 | 所有真实界面统一装进这个外框 |
| 代码面板 code | 深色、行号、等宽字体、15px/23.25px 行高、高亮行左侧白条；标签栏左边一句大白话、文件名退到右边灰色小字（`.tab.say`），不是重点的行压暗（`hfFocus`） | 展示真实文件；看的人不一定写代码，先告诉他这段在说什么 |
| 封面 | 3:4（1242×1656）+ 4:3（1656×1242），白、黑各一套，2 倍出图；固定的只有深灰舞台、左上签名、右上头像、数黑/普惠字体（`assets/kit/cover/brand.css`，白版 `body.light`），排版每支重新设计（`cover.md`） | 和视频一眼认得出是同一个人；内容不同排版就不同，不套模板 |
| 结尾卡 endcard | 标题（数黑 60px）+ 细线 + 一行署名（写在结尾那章的场景里），最后 0.8 秒压黑 | 统一收尾 |
| 字体 | 标题/字幕：阿里妈妈数黑体；正文/标注：阿里巴巴普惠体；代码：JetBrains Mono | 构建时按用到的字子集化 |
| 色彩 | 只有黑白灰；彩色只来自真实截图和录屏 | 克制，让内容本身发光 |
| 声音 | 原创合成配乐（92 BPM，跟着口播走），人声 -16 LUFS，成片 -10 LUFS，音乐在说话时自动退让（`audio.md`） | 每支视频听起来一致 |

## 可以按视频调整的参数（在 video.config.json，不改代码）

- `acts`：这支片子有哪几章（每个 act 对应 `src/scenes/<actId>.html`）。
- `aliases`：给口播节点起名字，场景里用 `C.<名字>`（如 `"ask": "l1"`）。
- `chapters`：导航文字和对应章节；没有章节的短视频可以设为 `[]`，导航就不出现。
- `navFrom` / `navUntil` / `sigAt`：导航出现、消失、签名写出的时间点（口播节点引用，如 `"actA.l2"`）。
- `noCaptions`：画面里自己就有文字的章（比如片尾字幕那样的尾幕）关掉底部字幕，如 `["actP"]`；SRT 照常完整。
- `tail`：最后一句后留多久。
- `lifts`（配乐高光）、`rides`（音量演示）、`loudness`：见 `audio.md`。
- `forbid`、`textReplace`：分平台出两个版本时用（一般写在 `video.config.neutral.json` 里）。`forbid` 列出这个版本不能出现的词（平台名等），build 时画面文字或字幕里还有就直接报错；`textReplace` 把画面文字里的词换掉（如窗口标题里的平台名、工具名）。
- `--intro`（配音、转写时，不在 config 里）：第一句前留几秒，写 0–0.5（`script.md` › 2 开头 3 秒）。

## 换人使用

这套 skill 的头像、签名、声音都是占位的，用户第一次用之前换成自己的。三样都放在 skill 的 `assets/brand/`，建工程时自动拷进工程；其余保持一致，就能得到同样风格的视频。

| 换什么 | 文件 | 要求 |
|---|---|---|
| 头像 | `assets/brand/avatar.png` | 500×500 的 PNG（正方形）；画面里会裁成圆（64px、白色描边），脸放在正中间 |
| 签名 | `assets/brand/signature.png` | 透明底、白色笔迹的 PNG，约 1470×380；左右不留白，笔迹贴着图的左右边。画面里按高 66px 缩放 |
| 声音 | `assets/brand/voice.json` | 在 Fish Audio 克隆用户自己的声音，把声音 id 填进 `reference_id`；API key 写在 `~/.config/mihua-video/keys.env`（`FISH_API_KEY=…`），不放进工程文件夹。不用 AI 配音、自己录口播的，这一项不用管 |

- 用户只给照片也行：`~/.cache/mihua-video/venv/bin/python scripts/make_brand.py --avatar <头像照片> --signature <签名照片>`，头像从中间裁成 500×500，签名（白纸深色笔的照片）抠成白字透明底、裁掉空白、高 380；纸上有阴影没抠干净，加 `--threshold` 调。
- 换完在 skill 文件夹里跑 `bash scripts/install.sh`，之后新建的工程都用新的。
- 已经建好的工程：把 `avatar.png`、`signature.png` 拷进工程的 `assets/img/`，`voice.json` 拷到工程根目录。
- 不想改 skill 里的文件，也可以建工程时指定：`bash scripts/new_project.sh <工程> --brand <放着 avatar.png、signature.png、voice.json 的文件夹>`。
- 结尾卡的署名、口播里的自我介绍，写用户自己的名字。
